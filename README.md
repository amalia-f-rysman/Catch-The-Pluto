# Catch-The-Pluto
A Processing Java game demonstrating object-oriented programming concepts, inheritance, collision detection, random object generation, and real-time user interaction.

## Focusing On:
- Using objects repeatedly in different contexts
- User based collision inputs
- Time based programs
- Encapsulation

## Overview
- Displays the planets in order
- User begins the came and has set time to catch the falling objects (Pluto)
